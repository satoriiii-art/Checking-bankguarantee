# Bank Guarantee Validator (RAG-пайплайн в n8n)

Pet-проект по автоматизированной проверке банковских гарантий на соответствие 44-ФЗ с использованием AI и векторной базы данных.

📌 Описание проекта

Checking Bank Guarantee — это интеллектуальная система автоматизированной проверки банковских гарантий на соответствие требованиям законодательства, включая Федеральный закон 44-ФЗ.

Проект решает проблему ручной, трудоёмкой проверки банковских гарантий, которая обычно занимает много времени и требует юридической экспертизы. Машинный анализ с помощью RAG-подхода позволяет:

выявлять нарушения и несоответствия;

автоматически находить в нормативной базе нужные юридические формулировки;

анализировать документ целиком и формировать экспертное заключение.

Этот проект реализует прототип, аналогичный тому, что тестируют крупные банки (например, Альфа-Банк) в своих внутренних сервисах по проверке банковских гарантий.

## 📌 Основные возможности
- Загрузка PDF-гарантий из Gmail
- Извлечение текста и разбиение на чанки
- Генерация эмбеддингов через HuggingFace
- Сохранение в Pinecone
- Поиск релевантных фрагментов из базы знаний
- Генерация ответа через LLM DeepSeek
- Анализ на соответствие юридическим требованиям

## 🛠 Стек технологий
- [n8n](https://n8n.io)
- [Pinecone](https://www.pinecone.io) — векторная база
- [DeepSeek LLM](https://deepseek.com)
- HuggingFace embeddings
- Google Drive / Gmail интеграции

## ⚙️ Как использовать
1. Импортируй `rag_pipeline.json` в n8n
2. Настрой API-ключи: Gmail, DeepSeek, Pinecone
3. Загрузи базу знаний (44-ФЗ) в Pinecone
4. Запусти процесс и отправь тестовую гарантию на почту
